# 충족 판정 데이터 (tools/judge)

화면의 '충족 판정' 보기는 `src/judge.js`(판정 로직)와 `data/judge.json`(전형별 판정 규칙)을 쓴다. `data/judge.json`은 이 폴더의 스크립트가 대학 파일에서 만든다.

```
python3 tools/judge/build.py              # data/judge.json 다시 만들기
python3 tools/judge/build.py --xlsx DIR   # 검수용 xlsx·csv도 함께(openpyxl 필요)
node tools/judge/test.cjs                 # 판정 사례 점검
node scripts/build.mjs                    # index.html 다시 만들기
```

## 언제 다시 돌리나
전형의 `min_flag`·`min_text`·`elig`·`elig_text`·`recommend`·`reg` 중 하나라도 바꾸거나 전형을 더하거나 빼면 `node scripts/build.mjs`가 막는다(`src` 지문이 다름). 다시 만든 뒤 바뀐 전형의 규칙을 눈으로 확인한다. 자동 분해(`parse_min.py`)는 수도권 대학 문구 형식에 맞춰져 있어, '모집단위 묶음 + 기준'이 여러 갈래인 문구는 틀리기 쉽다. 그런 전형은 `build.py`의 `OV`나 `ov_v010.py`의 `OV2`에 규칙을 직접 적는다. 같은 대학에 이름이 같은 전형이 있으면 키를 `(대학, 전형구분, 전형명)`으로 쓴다.

## 규칙 한 줄(`m`)
`label`(적용 모집단위), `areas`(국·수·영·탐·통사·통과·한국사), `tam`(탐구 방식: 상위 1 / 평균 / 각각 별도 / 통합과학만), `n`·`kind`(합·각·미적용·한국사만·영어·한국사만)·`val`, `req`(필수 영역: 수·국·탐·국·수 모두·국·수 중 1개 이상·수·탐 모두, 문구가 애매하면 `(확인 필요)`), `hist`(한국사), `eng`(영어 별도), `etc`(대체 응시·등급 보정·절사/반올림·조건부 통합 등).

## 판정 원칙
- 결과는 충족 / 미충족 / 확인 필요. 합격 가능성은 보지 않는다.
- 원문 해석이 갈리면 가능한 해석을 모두 넣어 보고, 결과가 같을 때만 확정한다. 입력하지 않은 등급은 1과 9를 모두 넣어 본다.
- 수능최저는 모집단위 중 하나라도 충족하면 충족이고, 못 맞추는 모집단위는 메모로 보여 준다.
- 지역 요건은 `reg`로 판정한다: 같은 시·도면 충족, 시·도보다 좁은 지정 지역이면 확인 필요, 다른 시·도면 미충족.
- 학폭·이수 학기·거주·성별(여대) 등 입력받지 않는 요건은 메모로만 보여 준다.
- 2028 수능 탐구는 통합사회·통합과학이므로 원문의 '사탐'·'과탐'은 통합사회·통합과학으로 읽는다.
