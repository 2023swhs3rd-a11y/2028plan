# 2028 대입전형 시행계획 요약

2028학년도 대학입학전형 시행계획(대학별 PDF)을 바탕으로 일반대학 50곳, 교육대학 10곳, 과학기술원 5곳의 학생부교과·학생부종합·논술·정시(수능위주) 전형과 2027 대비 변경사항을 정리한 대시보드입니다.

- 보기: `index.html` (단일 파일, 인터넷 연결 없이도 열림)
- 출처: 각 대학이 공개한 2028학년도 대입전형 시행계획 PDF. 외부 사교육 자료는 참고하지 않았습니다.
- 주의: 요약 과정에서 누락이나 오기가 있을 수 있습니다. 지원 전에는 반드시 대학별 시행계획과 모집요강 원문을 확인하세요.

## GitHub Pages로 공개하는 방법

1. GitHub에서 새 저장소(Public)를 만듭니다.
2. 이 폴더의 `index.html`, `README.md`, `LICENSE`를 업로드합니다 (Add file › Upload files).
3. Settings › Pages › Build and deployment에서 Source를 `Deploy from a branch`, Branch를 `main` / `(root)`로 두고 Save합니다.
4. 1~2분 뒤 `https://<계정>.github.io/<저장소>/` 주소로 열립니다.
